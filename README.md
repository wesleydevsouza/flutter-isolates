# 📊 Flutter Isolates & Charts Study

A simple Flutter project created for learning and experimenting with **Isolates** and **chart rendering**.

This app demonstrates:

* Running background computations using Dart **Isolates**
* Visualizing data through **interactive charts**
* Clean architecture for async operations

Useful for those exploring performance optimization and parallel processing in Flutter apps.
